# SocketSight 使用条款

**生效及最近更新日期：2026年9月6日**

安装或使用 SocketSight，即表示你已阅读并同意本条款。如果你不同意其中任何内容，请不要安装或使用本产品。

## 1. 产品用途

SocketSight 是一款基于规则的 Windows 网络连接观察工具。它可以显示操作系统报告的特定 TCP 连接，并根据你的设置在本地记录事件或发出提醒。

SocketSight 不会读取网络数据包的具体内容，也不会自动封锁连接。它不能单独判断某个软件是否安全、是否包含恶意程序，或某项活动是否一定发生。

## 2. 不构成安全结论或专业服务

SocketSight 是信息辅助工具，不能替代杀毒软件、防火墙、入侵检测系统或专业网络安全调查。出现规则匹配不代表设备一定受到感染或存在违法活动；没有匹配也不代表设备绝对安全。

你需要结合实际情况解读结果、妥善保护导出的记录，并自行决定是否向合格的专业人员寻求帮助。

为了正常运行，SocketSight 需要读取 Windows 提供的网络和进程信息。由于系统权限或 Windows 本身的限制，部分进程信息可能无法取得，显示结果也可能存在遗漏或误差。

你需要自行保护使用本产品产生的规则、设置、日志、导出文件及其他本地记录。
