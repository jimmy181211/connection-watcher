# TCP连接监视器使用说明

## 主要作用

简单来说，这个工具可以帮你**盯住你指定的IP地址或端口**。它可以：

- 自动记录连接出现的时间
- 记录本地和远程IP与端口
- 尽可能记录连接相关程序、PID和程序路径
- 根据用户设置选择静默记录、托盘提醒或弹窗警报
- 保存记录，方便用户之后查看或提供给网络安全人员
- 记录还可以帮助用户确认相同目标后来是否再次出现。

## 工具如何工作

你需要先创建规则，通过设置规则告诉程序要监视哪个IP或端口。然后你需要启用规则并开始监控。程序每1秒检查一次Windows的TCP连接列表。只有符合已启用规则的连接才会被处理，其他普通连接不会触发记录或提醒。

连接匹配到规则时，程序会按照你的选择：

- **静默记录**：只写入CSV日志，不改变托盘图标，也不显示未读数量。
- **托盘提示并记录**：不弹窗；托盘图标变为警告状态，打开事件页后清除提示。
- **弹窗警报并记录**：第一次匹配立即显示窗口；窗口打开时，后续匹配更新同一窗口。关闭后按照规则设置的间隔重新提醒。

首页会显示三种操作对应的简洁标识。“监视规则”使用“标识 + 简短名称”，“事件记录”中的“操作”列只显示标识，因此即使列宽较窄也能快速分辨：

- `1 ●` 灰色圆形：静默记录
- `2 ▲` 橙色三角形：托盘提示并记录
- `3 ◆` 红色菱形：弹窗警报并记录

即使不方便辨认颜色，也可以通过数字和形状区分。将鼠标放在规则或事件记录的标识上，可以查看完整操作名称。

#### *需要注意*：
1. 规则匹配只表示用户关注的连接出现了，不能直接证明电脑感染了病毒。
2. 本工具**只负责记录和提醒**，是否需要采取安全措施，还应结合杀毒扫描和专业人员的判断。

## 第一次运行

1. 安装时从七种支持的语言中选择一种；便携版第一次打开时会让用户选择语言。
2. 打开“监视规则”。
3. 点击“新建规则”。
4. 使用规范字段填写监视条件。
5. 检查表单底部的规则预览。
6. 保存并启用规则。
7. 返回首页，点击“开始监控”。

### 示例

如果要监视电脑任意本地端口是否再次访问`103.1.40.235:1433`（远程服务器的IP和端口）

- 规则类型：TCP连接
- 远程IP：`103.1.40.235`
- 远程端口：`1433`
- 本地端口：任意
- 匹配后操作：弹窗警报并记录
- 重复提醒间隔：5分钟

## 日志记录

日志记录默认保存在：
```text
%LOCALAPPDATA%\ConnectionWatcher\Logs\
```
“事件记录”中的每个新匹配连接只显示一条记录。同一个连接持续数小时也不会每秒重复记录；“状态”会显示“活动中”或“已结束”，“已观察时长”会在连接活动时自动更新，并在结束后固定下来。

为了方便查看，表格只显示主要字段。双击任意一行可打开“事件详细信息”，查看匹配规则、本地端点、TCP状态、PID、程序路径和操作；活动状态与时长会继续更新，也可以一键复制完整记录。

已观察时长从程序第一次发现连接开始计算，不一定等于连接的实际总时长。停止监控后，程序无法判断连接在这段时间内是否中断，因此重新开始监控时会建立一条新的观察记录。后台CSV只在发现和结束时写入生命周期信息，不会每秒写入；软件会将它们合并成事件页中的一条记录。

连接消失两个检查周期后再次出现，才会建立新记录。
日志总上限默认为25MB，可以在“设置”中调整为5–500MB。日志最多分为5个文件，达到用户设置的上限后自动删除最旧的记录。

## 帮助中心

在“设置”中点击“打开帮助中心”，可以直接在软件内查看项目说明和使用说明。文档会跟随当前界面语言切换。

## 启动和提醒声音设置

- **登录 Windows 后启动程序**：登录后自动打开程序，减少忘记启动监视工具的情况；它本身不会自动开始监控。
- **程序打开后自动开始监控**：每次打开程序时，使用已启用的规则自动开始监控。
- **紧急提醒声音**：使用程序内置的短提示音，不依赖 Windows 事件声音方案。音量可在10%–100%之间调节，默认40%；“测试声音”和真正的紧急警报使用相同音量，Windows系统音量仍然有效。

## 重要限制

1. 每1秒检查一次；少于1秒的短连接可能被遗漏。
2. 第一版**只监视TCP**，不监视UDP。
3. TCP连接表没有完全可靠的发起方向字段，因此程序无法判断一个连接是哪方发起的
4. 某些系统或受保护进程的程序路径可能因Windows权限而无法读取；PID和可获得的名称仍会记录。
5. 程序退出、停止监控、电脑休眠期间不会监视。
6. “已观察时长”从程序首次发现连接开始计算，精度约为1秒，不代表Windows记录的准确连接建立时间。
7. 程序只负责记录和提醒，不会关闭程序、修改防火墙或封锁IP

## 隐私和权限

1. 不需要管理员权限。
2. 不需要登录、用户名、密码或邮箱。
3. 不连接开发者服务器，不上传日志。
4. 不读取数据包正文。
5. 配置保存在 `%LOCALAPPDATA%\ConnectionWatcher\config.json`

## 卸载

安装版可以通过Windows“已安装的应用”卸载。卸载会删除程序，但默认保留`%LOCALAPPDATA%\ConnectionWatcher`中的配置和日志，防止调查记录意外丢失。如确定不再需要，可以手动删除该数据目录。
