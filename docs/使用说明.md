## 这是什么工具？

SocketSight 可以帮你监视指定的 IP 地址或端口。

发现符合规则的 TCP 连接后，程序会记录时间、IP、端口，以及 Windows 能够提供的相关进程信息，并按照你的设置提醒你。

它只负责观察、记录和提醒，不会关闭程序、修改防火墙或封锁 IP。

## 安装和第一次打开

安装时选择的语言同时用于安装程序和软件界面。升级安装新版时，如果重新选择了语言，软件会使用新语言；已有规则、设置和日志不会被删除。

如果程序启动超过约 0.5 秒，SocketSight 会显示一个简短的启动画面。画面上的文字只是启动提示，主窗口准备好后会自动消失。

## 快速开始

1. 打开“监视规则”。
2. 点击“新建规则”。
3. 填写要监视的 IP 地址或端口。
4. 保存并启用规则。
5. 返回首页，点击“开始监控”。

例如，要监视电脑是否连接到 `103.1.40.235:1433`：

- 远程 IP：`103.1.40.235`
- 远程端口：`1433`
- 本地端口：任意
- 匹配后操作：弹窗警报并记录
- 重复提醒间隔：5 分钟

## 检查频率

程序默认每 1 秒检查一次连接。你可以在首页将间隔调整为 0.5–10 秒，步长为 0.5 秒。

间隔越短，越容易发现短暂连接，但占用的资源也会更多。即使设置为 0.5 秒，仍可能漏掉在两次检查之间出现并消失的连接。

只有已启用的规则会触发记录和提醒。

## 匹配后会发生什么？

- **静默记录**：只写入日志，不提醒。
- **托盘提示并记录**：托盘图标变为警告状态，打开事件页后清除提示。
- **弹窗警报并记录**：首次匹配时弹窗，后续匹配会更新同一个窗口。

首页和事件列表中的数字、形状标识，可以帮助你快速区分这三种操作。

## 如何查看事件？

同一个连接只显示一条记录，不会每秒重复出现。

- 连接存在时显示“活动中”。
- 连接结束后显示“已结束”。
- “已观察时长”在连接活动时更新，结束后不再变化。
- “应用”一栏会优先显示产品名称，没有时显示进程名称。
- 双击记录可以查看进程、PID、路径、父级进程和 Windows 服务等详细信息，也可以复制记录。

连接从 Windows 列表中消失 2 秒后，才会被标记为结束。2 秒内重新出现，仍算同一条记录；更晚再次出现，则会新建记录。

时长从程序第一次发现连接开始计算，不一定等于连接的真实持续时间。停止监控后，程序无法继续观察；重新开始时会新建记录。

## 记录该如何理解？

规则匹配只表示你关注的连接出现了，不代表电脑一定感染病毒。

浏览器、代理、VPN 或网页组件可能在后台运行。因此，记录中的进程信息只能帮助判断相关应用，不能保证它就是最终发起连接的程序。

TCP 连接列表也无法可靠判断是哪一方发起连接。受 Windows 权限限制，部分路径、文件信息、父级进程或服务可能无法获取。

如需判断是否安全，请结合杀毒软件扫描，或咨询专业人员。

## 帮助中心和软件更新

在“设置”中点击帮助中心旁边的“打开”，即可查看项目说明和使用说明。文档会跟随界面语言切换。

点击“立即检查”后，程序才会向 GitHub 查询新版本。程序不会自动下载、安装或运行更新。

在“设置”中打开“反馈”，可以写下建议或问题。程序会在浏览器中打开预先填写的 GitHub Issue 页面；请检查内容后自行提交。默认不会附加日志或连接记录。

## 日志、提醒声音和其他设置

日志默认保存在：

```text
%LOCALAPPDATA%\ConnectionWatcher\Logs\
```

CSV 只在发现连接和连接结束时写入，不会每秒写入。同一个连接在事件页面中只显示一条记录。

“清空显示”只会隐藏页面记录，不会删除 CSV。重新打开软件后，旧事件仍然隐藏；新事件会正常显示。

日志默认上限为 25 MB，可在“设置”中调整为 5–500 MB。超过上限后，程序会自动删除最旧的文件，最多保留 5 个文件。

紧急提醒声音用于弹窗警报。可以在设置中调节。基础分贝受Windows电脑音量影响

## 隐私、权限和卸载

- 不需要管理员权限、账号或密码。
- 不读取网络数据包正文。
- 不上传规则和日志。
- 只有用户手动检查更新或打开反馈页面时，程序才会连接 GitHub。

卸载程序时，配置和日志默认会保留。如确定不再需要，可以手动删除：

```text
%LOCALAPPDATA%\ConnectionWatcher
```
