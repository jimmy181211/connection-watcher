# TCP连接监视器

## 项目背景与意义

在排查异常网络连接时，我们经常需要回答一个简单但很难及时确认的问题：
> 我的电脑是否连接过某个IP地址或端口？如果连接过，是在什么时间、由哪个程序建立的？

Windows资源监视器可以查看当前的网络活动，但需要用户主动打开并持续观察。短暂连接可能很快消失，长时间盯着窗口也不现实。它也不会针对指定目标自动提醒或保存连续记录。
TCP连接监视器解决了这个问题。用户设置需要关注的IP或端口后，程序会在后台持续检查。发现匹配连接时，它会记录时间、地址、端口以及能够获取的程序和PID，并根据设置进行提醒。
本工具不是为了取代资源监视器或杀毒软件，而是帮助用户更方便地监视指定目标、保留记录，并为后续安全调查提供信息。

## 项目概述

TCP连接监视器是一款小型、基于规则的**Windows网络连接观察工具**。用户可以明确指定自己关心的远程IP、远程端口或本地端口。当Windows报告的TCP连接符合某条已启用规则时，程序会按照该规则选择的方式记录或提醒用户。

简单来说，这个工具就是帮你盯住某个指定的IP地址或端口。你先告诉它要监视什么，例如103.1.40.235:1433。开始监控后，只要电脑连接到这个目标，它就会记录连接时间、活动或结束状态、已观察时长、程序和PID等信息，并根据你的设置选择**静默记录、托盘提醒或弹窗警报。**

它只负责告诉你：“你关注的连接出现了。”它不会擅自把其他网络连接判断为可疑，也不能仅凭一次连接确定电脑感染了病毒。你可以把记录下来的信息交给网络安全团队，帮助他们进一步调查。

## 项目结构

```text
connection-watcher/
├── ConnectionWatcher.sln
├── src/
│   ├── ConnectionWatcher.Core/
│   └── ConnectionWatcher.App/
├── tests/
│   ├── ConnectionWatcher.Tests/
│   └── ConnectionWatcher.UiSmoke/
├── docs/
├── packaging/
└── Final-Share/
    ├── TCP-Connection-Watcher-Setup-win-x64.exe
    ├── SHA256SUMS.txt
    └── Docs/
```

- `ConnectionWatcher.sln`：整个项目的解决方案文件。
- `src/ConnectionWatcher.Core`：核心逻辑，包括设置、规则、Windows TCP连接读取、连接去重和CSV日志。
- `src/ConnectionWatcher.App`：支持七种语言切换的Windows界面，包括主窗口、规则编辑、内置帮助中心、托盘提醒和警报窗口。
- `tests`：功能测试和界面测试；当前功能测试共有16项。
- `docs`：七种语言的项目说明与使用说明。
- `packaging`：安装包定义和便携版说明。
- `Final-Share`：最终对外发送的目录，提供一个多语言安装包、三种语言的说明文档与SHA-256校验文件。

## 构建与验证

在Windows上构建源代码需要.NET 8 SDK。

```powershell
dotnet build ConnectionWatcher.sln --configuration Release
dotnet run --project tests\ConnectionWatcher.Tests\ConnectionWatcher.Tests.csproj --configuration Release
```

正式发布包包含`SHA256SUMS.txt`，接收者可以在PowerShell中使用`Get-FileHash`检查文件是否完整。
