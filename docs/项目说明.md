# TCP连接监视器

## 项目背景与意义

在排查异常网络连接时，我们经常需要回答一个简单但很难及时确认的问题：
> 我的电脑是否连接过某个IP地址或端口？如果连接过，是在什么时间、Windows当时将它关联到了哪个进程，还能找到哪些与应用有关的背景信息？

Windows资源监视器可以查看当前的网络活动，但需要用户主动打开并持续观察。短暂连接可能很快消失，长时间盯着窗口也不现实。它也不会针对指定目标自动提醒或保存连续记录。
TCP连接监视器解决了这个问题。用户设置需要关注的IP或端口后，程序会在后台持续检查。发现匹配连接时，它会记录时间、地址、端口、Windows报告的连接所属进程，以及能够获取的文件信息、父级进程和Windows服务背景，并根据设置进行提醒。
本工具不是为了取代资源监视器或杀毒软件，而是帮助用户更方便地监视指定目标、保留记录，并为后续安全调查提供信息。

## 项目概述

TCP连接监视器是一款小型、基于规则的**Windows网络连接观察工具**。用户可以明确指定自己关心的远程IP、远程端口或本地端口。当Windows报告的TCP连接符合某条已启用规则时，程序会按照该规则选择的方式记录或提醒用户。

简单来说，这个工具就是帮你盯住某个指定的IP地址或端口。你先告诉它要监视什么，例如103.1.40.235:1433。开始监控后，只要电脑连接到这个目标，它就会记录连接时间、活动或结束状态、已观察时长、Windows报告的所属进程、PID以及能够获取的应用背景信息，并根据你的设置选择**静默记录、托盘提醒或弹窗警报。**

检查间隔默认为1秒。用户可以按0.5秒的步长，在0.5–10秒之间调整。较短的间隔更容易发现短暂连接；较长的间隔占用资源更少，但可能漏掉短暂连接。

它只负责告诉你：“你关注的连接出现了。”它不会擅自把其他网络连接判断为可疑，也不能仅凭一次连接确定电脑感染了病毒。你可以把记录下来的信息交给网络安全团队，帮助他们进一步调查。

## 项目结构

```text
connection-watcher/
├── ConnectionWatcher.sln
├── RELEASE_NOTES.md
├── src/
│   ├── ConnectionWatcher.Core/
│   └── ConnectionWatcher.App/
├── tests/
│   ├── ConnectionWatcher.Tests/
│   └── ConnectionWatcher.UiSmoke/
├── docs/
├── learning/
├── scripts/
│   └── build-release.ps1
├── packaging/
└── Final-Share/
    ├── TCP-Connection-Watcher-Setup-win-x64.exe
    ├── SHA256SUMS.txt
    └── Docs/
```

- `ConnectionWatcher.sln`：整个项目的解决方案文件。
- `src/ConnectionWatcher.Core`：核心逻辑，包括设置、规则、Windows TCP连接读取、基于时间的连接跟踪、进程背景信息和兼容旧版本的CSV日志。
- `src/ConnectionWatcher.App`：支持七种语言切换的Windows界面，包括主窗口、规则编辑、事件详情、内置帮助中心、更新检查、托盘提醒和警报窗口。
- `tests`：20项功能及兼容性测试，以及多语言界面和DPI缩放测试。
- `docs`：七种语言的项目说明与使用说明。
- `learning`：开发者教程和架构学习材料。
- `scripts/build-release.ps1`：依次完成验证，并自动生成`artifacts`、`dist`和`Final-Share`。
- `packaging`：安装包定义和便携版说明。
- `Final-Share`：本地使用且不上传Git的最终分享目录，包含一个多语言安装包、七种语言文档、发布说明和SHA-256校验文件。

## 构建与验证

在Windows上构建源代码需要.NET 8 SDK。

```powershell
dotnet build ConnectionWatcher.sln --configuration Release
dotnet run --project tests\ConnectionWatcher.Tests\ConnectionWatcher.Tests.csproj --configuration Release
```

正式发布包包含`SHA256SUMS.txt`，接收者可以在PowerShell中使用`Get-FileHash`检查文件是否完整。

维护者可以运行`scripts\build-release.ps1`，一次完成构建、测试、发布、安装包生成、最新版文档复制和校验文件生成。
