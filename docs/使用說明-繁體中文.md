## 這是什麼工具？

SocketSight 可以幫您監視指定的 IP 位址或連接埠。

符合規則的 TCP 連線出現後，程式會記錄時間、IP、連接埠，以及 Windows 能提供的程序資訊，再依照您的設定提醒您。

它只負責觀察、記錄和提醒，不會關閉程式、修改防火牆或封鎖 IP 位址。

## 安裝與快速開始

安裝時選擇的語言也會套用到軟體介面。升級安裝時選擇其他語言會更新介面語言一次；原有規則、設定和記錄都會保留。

如果啟動時間超過約 0.5 秒，SocketSight 會顯示簡短的啟動畫面；主視窗準備好後會自動關閉。

1. 開啟「監視規則」。
2. 選擇「新增規則」。
3. 輸入要監視的 IP 位址或連接埠。
4. 儲存並啟用規則。
5. 返回「首頁」，選擇「開始監控」。

例如，要監視 `103.1.40.235:1433`：

- 遠端 IP：`103.1.40.235`
- 遠端連接埠：`1433`
- 本機連接埠：任意
- 符合後操作：彈出警報並記錄
- 重複提醒間隔：5 分鐘

## 檢查頻率

預設每 1 秒檢查一次。您可以在首頁用 0.5 秒為步進，將間隔調整為 0.5–10 秒。

間隔越短越容易發現短暫連線，但會使用較多資源。即使設為 0.5 秒，仍可能錯過在兩次檢查之間出現又消失的連線。

只有已啟用的規則會產生記錄或提醒。

## 符合規則後會怎樣？

- **靜默記錄**：只寫入記錄，不提醒。
- **系統匣提示並記錄**：系統匣圖示變成警告狀態；開啟事件記錄後提示會清除。
- **彈出警報並記錄**：第一次符合時顯示視窗，之後的符合會更新同一個視窗。

首頁和事件列表中的數字、形狀可以幫助您分辨三種操作。

## 查看事件

同一條連線只顯示一筆記錄，不會每秒新增一列。

- 連線存在時顯示「活動中」。
- 連線結束後顯示「已結束」。
- 「已觀察時長」會在活動時更新，結束後固定不變。
- 「應用程式」欄位會優先顯示檔案產品名稱，沒有時顯示程序名稱。
- 雙擊記錄可以查看程序、PID、路徑、父程序、Windows 服務等詳細資料，也可以複製記錄。

連線從 Windows 清單消失滿 2 秒後才會標記為結束。2 秒內重新出現仍是同一筆記錄；更晚再次出現則會建立新記錄。

時長從程式第一次發現連線開始計算，不一定等於連線的實際持續時間。停止監控後程式無法繼續觀察；重新開始時會建立新記錄。

## 如何理解記錄

規則符合只表示您關注的連線出現，不代表電腦一定感染惡意軟體。

瀏覽器、代理伺服器、VPN 或網頁元件可能已在背景執行。程序資訊只能協助判斷相關應用程式，不能保證它就是最終發起連線的程式。

TCP 連線清單也無法可靠判斷是哪一方發起連線。Windows 權限限制可能使部分路徑、檔案資訊、父程序或服務無法取得。

如需判斷安全問題，請結合防毒軟體掃描或諮詢專業人員。

## 說明中心與軟體更新

在「設定」中點擊說明中心旁的「開啟」，即可查看專案說明和使用說明；文件會跟隨目前介面語言切換。

點擊「立即檢查」後，程式才會向 GitHub 查詢新版本。程式不會自動下載、安裝或執行更新。

在「設定」中開啟「意見回饋」，可以寫下建議或問題。程式會在瀏覽器中開啟預先填寫的 GitHub Issue 頁面；請檢查內容後自行提交。預設不會附加記錄或連線資料。

## 記錄、聲音和其他設定

記錄預設儲存在：

```text
%LOCALAPPDATA%\ConnectionWatcher\Logs\
```

CSV 只在發現連線和觀察結束時寫入，不會每秒寫入。事件記錄會將同一條連線合併為一列。

「清空顯示」只隱藏事件頁面的記錄，不會刪除 CSV。重新開啟軟體後舊事件仍保持隱藏，新事件會正常顯示。

記錄上限預設為 25 MB，可在「設定」中調整為 5–500 MB。程式最多保留 5 個檔案，超過上限後會自動刪除最舊檔案。

「登入 Windows 後啟動程式」只會自動開啟程式，不會自動監控。「程式開啟後自動開始監控」才會在啟動時使用已啟用的規則。

緊急提醒聲音用於彈出警報。您可以在「設定」中調整音量；「測試聲音」使用相同音量，Windows 系統音量也會影響結果。

## 隱私、權限與解除安裝

- 不需要系統管理員權限、帳號或密碼。
- 不讀取網路封包內容。
- 不上傳規則和記錄。
- 只有手動檢查更新或開啟回饋頁面時才會連線 GitHub。

解除安裝時，設定和記錄預設會保留。如確定不再需要，可以手動刪除：

```text
%LOCALAPPDATA%\ConnectionWatcher
```
