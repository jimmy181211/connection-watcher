# TCP連線監視器使用說明

## 主要用途

簡單來說，本工具可協助您**監視自己指定的IP位址或連接埠**。它可以：

- 自動記錄連線出現的時間
- 記錄本機和遠端IP位址與連接埠
- 在可取得時記錄相關程式、PID和程式路徑
- 依設定選擇靜默記錄、系統匣提示或彈出警報
- 儲存記錄，方便日後查看或提供給網路安全人員
- 協助確認相同目標之後是否再次出現新連線

## 工具如何運作

先建立一條規則，告訴程式要監視哪個IP位址或連接埠；接著啟用規則並開始監控。程式每1秒檢查一次Windows的TCP連線清單。只有符合已啟用規則的連線才會被處理，其他一般連線不會產生記錄或提醒。

連線符合規則時，程式會執行您選擇的動作：

- **靜默記錄**：只寫入CSV記錄，不改變系統匣圖示，也不顯示未讀數量。
- **系統匣提示並記錄**：不彈出視窗；系統匣圖示會變成警告狀態，開啟事件記錄頁面後清除提示。
- **彈出警報並記錄**：第一次符合時立即顯示視窗；視窗開啟期間，後續符合會更新同一視窗。關閉後由規則設定的間隔決定何時可以再次提醒。

首頁會顯示三種動作的簡潔標記。**監視規則**使用標記加簡短名稱，**事件記錄**中的動作欄只顯示標記：

- `1 ●` 灰色圓形：靜默記錄
- `2 ▲` 橙色三角形：系統匣提示並記錄
- `3 ◆` 紅色菱形：彈出警報並記錄

即使不方便辨認顏色，也可利用數字和形狀區分。將滑鼠移到規則或事件標記上，可查看完整動作名稱。

#### *重要提醒：*

1. 規則符合只表示您關注的連線出現了，不能證明電腦感染病毒。
2. 本工具**只負責記錄與提醒**。是否採取其他安全措施，還應參考防毒掃描和專業人員的判斷。

## 第一次使用

1. 安裝時選擇七種支援語言之一；可攜版第一次開啟時也會要求選擇語言。
2. 開啟**監視規則**。
3. 選擇**新增規則**。
4. 在表單欄位中輸入監視條件。
5. 檢查表單底部的規則預覽。
6. 儲存並啟用規則。
7. 回到**首頁**並選擇**開始監控**。

### 範例

若要監視電腦的任意本機連接埠是否再次連線到`103.1.40.235:1433`，請建立以下規則：

- 規則類型：TCP連線
- 遠端IP：`103.1.40.235`
- 遠端連接埠：`1433`
- 本機連接埠：任意
- 符合時的動作：彈出警報並記錄
- 重複提醒間隔：5分鐘

## 記錄

記錄儲存在：

```text
%LOCALAPPDATA%\ConnectionWatcher\Logs\
```

每個新符合連線在**事件記錄**中只顯示一列。相同連線即使持續數小時，也不會每秒重複記錄。**狀態**會顯示活動中或已結束，**已觀察時長**會在活動期間更新，結束後固定。

為了方便閱讀，表格只顯示主要欄位。連按兩下任意一列可開啟**事件詳細資料**，查看符合規則、本機端點、TCP狀態、PID、程式路徑和操作；活動狀態與時長會繼續更新，也可以一鍵複製完整記錄。

已觀察時長從程式第一次看到連線時開始，因此不一定等於連線的完整實際時長。停止監控後，程式無法判斷連線是否在空白期間中斷，因此再次開始監控會建立新的觀察記錄。背景CSV只會在發現連線和觀察結束時寫入生命週期資料；程式會將它們合併成事件頁面中的一列。

連線連續兩次檢查都消失，之後再次出現時，也會建立新記錄。

記錄總上限預設為25MB，可在**設定**中改為5–500MB。程式最多使用5個記錄檔，達到上限後會自動移除最舊的記錄。

## 說明中心

在**設定**中選擇**開啟說明中心**，即可在程式內查看專案說明與使用說明。文件會跟隨目前的介面語言。

## 啟動與警報聲音設定

- **登入 Windows 後啟動程式**：登入後開啟程式，避免忘記啟動；它本身不會開始監控。
- **程式開啟後自動開始監控**：每次開啟程式時，使用已啟用規則自動開始監控。
- **緊急提醒聲音**：使用程式內建的短提示音，不依賴Windows事件音效。音量可設為10%–100%（預設40%）；測試聲音和真正警報使用相同設定，Windows系統音量仍然有效。

## 重要限制

1. 程式每1秒檢查一次，因此可能遺漏持續不到1秒的連線。
2. 第1版**只監視TCP**，不監視UDP。
3. Windows TCP連線表沒有完全可靠的連線發起方欄位，因此程式無法判斷哪一方建立連線。
4. Windows權限可能阻止程式讀取某些系統或受保護處理程序的路徑；仍會記錄PID和可取得的程式名稱。
5. 程式關閉、停止監控或電腦休眠時不會監視。
6. 已觀察時長從程式首次發現連線開始，精確度約為1秒，並非Windows提供的精確連線建立時間。
7. 程式只負責記錄與提醒，不會關閉程式、修改防火牆或封鎖IP位址。

## 隱私與權限

1. 不需要系統管理員權限。
2. 不需要登入、使用者名稱、密碼或電子郵件地址。
3. 程式不會連線到開發者伺服器或上傳記錄。
4. 不會讀取網路封包內容。
5. 設定儲存在`%LOCALAPPDATA%\ConnectionWatcher\config.json`。

## 解除安裝

可透過Windows的**已安裝的應用程式**移除安裝版本。解除安裝會刪除程式，但預設保留`%LOCALAPPDATA%\ConnectionWatcher`中的設定和記錄，避免意外遺失調查資料。確定不再需要後，可手動刪除此資料夾。
