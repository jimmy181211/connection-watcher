# SocketSight 隐私政策

**生效及最近更新日期：2026年9月6日**

SocketSight 以在 Windows 设备本机运行、尽量减少数据传输为设计原则。本政策说明应用会读取哪些信息、这些信息如何保存在你的电脑上，以及哪些由你主动发起的操作会连接第三方服务。

## 1. 我们不会做什么

使用 SocketSight 无需注册账号。应用不包含广告追踪、行为分析或云端遥测，也不会出售个人信息。

## 2. 应用会在本机读取哪些信息

启用监控后，SocketSight 会读取 Windows 提供的 TCP 连接表，并仅处理符合你所创建规则的连接。根据 Windows 当时能够提供的信息，本地事件可能包括：

- 本地及远程 IP 地址与端口；
- TCP 状态和观察时长；
- 进程名称、进程标识符及可执行文件路径；
- 文件产品、公司及描述信息；
- 父进程或 Windows 服务背景；
- 所匹配的监控规则。

SocketSight 不会读取或分析网络数据包的具体内容。你的规则、设置、匹配事件及 CSV 日志都保存在自己的电脑上，应用不会把这些内容上传给我们。

## 3. 本地数据如何保存和删除

设置和监控规则保存在当前 Windows 用户的本地应用数据目录中，事件记录则写入本地 CSV 文件。日志采用最多五个文件的轮换机制；达到上限后，最旧的记录会被优先移除。

你可以从 SocketSight 打开日志目录，并通过 Windows 删除日志或已导出的 CSV 文件。请注意，卸载应用不一定会自动删除你创建的日志和设置；如果不再需要，请另行删除这些本地文件。

## 4. 哪些操作会产生网络请求

只有在你主动使用以下功能时，SocketSight 才会连接 GitHub：

- **检查更新：**应用会通过 GitHub API 获取公开的版本信息。GitHub 可能收到 IP 地址、请求时间和 SocketSight 应用标识等常规请求信息。
- **提交反馈：**应用会在浏览器中生成一份 GitHub Issue 草稿，并预先填入你提供的文字。你可以在发送前检查和修改全部内容；只有你确认提交后，信息才会发送。如果你选择附加基本诊断信息，草稿还可能包含应用版本、Windows 版本和界面语言，但不会包含日志或网络连接记录。

这些交互同时受 GitHub 自身隐私政策约束。请不要在公开 Issue 中填写密码、私人网络记录、机密文件路径或其他敏感信息。

## 5. 与 Windows 的本地集成

如果启用“登录 Windows 后启动”，SocketSight 会为当前 Windows 用户创建本地启动配置。这项设置只用于在本机启动应用，不会发送给我们。

## 6. 未成年人

SocketSight 是面向成年用户的通用技术工具，并非为 13 岁以下儿童设计。我们不会有意收集儿童的个人信息。

## 7. 政策更新与联系我们

如果 SocketSight 处理信息的方式发生变化，我们可能更新本政策，并在页面顶部标明最新日期。如有隐私问题，可通过项目的 [GitHub Issues](https://github.com/jimmy181211/connection-watcher/issues) 联系我们。由于 Issue 可能公开显示，请不要在其中填写敏感信息。
