# TCP連線監視器

## 專案背景與用途

排查異常網路連線時，我們常需要回答一個看似簡單、卻很難及時確認的問題：

> 我的電腦是否曾連線到某個IP位址或連接埠？如果有，是在什麼時間，Windows將它與哪個處理程序關聯，又能取得哪些應用程式背景資料？

Windows資源監視器可以顯示目前的網路活動，但使用者必須主動開啟並持續查看。短暫連線可能很快消失，長時間盯著視窗也不實際。它也不會針對指定目標自動提醒或保留連續記錄。

TCP連線監視器可以解決這個問題。使用者選擇要關注的IP位址或連接埠後，程式會在背景檢查符合條件的連線。發現連線時，它會記錄時間、位址、連接埠、Windows回報的連線擁有者，以及能夠取得的檔案、父處理程序和Windows服務資料，並依照設定提醒使用者。

本工具不是要取代資源監視器或防毒軟體，而是協助使用者監視指定目標、保留記錄，並為後續安全調查提供資料。

## 專案概述

TCP連線監視器是一款小型、以規則為基礎的**Windows網路連線觀察工具**。使用者可以指定關心的遠端IP、遠端連接埠或本機連接埠。當Windows回報的TCP連線符合已啟用規則時，程式會依該規則記錄或提醒。

簡單來說，它能幫您看守指定的IP位址或連接埠。例如，可以要求它監視`103.1.40.235:1433`。開始監控後，只要電腦連線到此目標，程式便會記錄連線時間、活動或結束狀態、已觀察時長、Windows回報的擁有者、PID，以及能夠取得的應用程式背景資料。依照設定，它可以**靜默記錄、顯示系統匣提示或彈出警報視窗。**

預設檢查間隔為1秒。使用者可以用0.5秒為步進，在0.5至10秒之間調整。較短的間隔較容易發現短暫連線；較長的間隔占用資源較少，但可能錯過短暫連線。

程式只會告訴您：「您要求關注的連線出現了。」它不會把其他連線擅自標示為可疑，也不能僅憑一次連線證明電腦感染病毒。記錄的資料可以提供給網路安全團隊進一步調查。

## 專案結構

```text
connection-watcher/
├── ConnectionWatcher.sln
├── RELEASE_NOTES.md
├── src/
│   ├── ConnectionWatcher.Core/
│   └── ConnectionWatcher.App/
├── tests/
│   ├── ConnectionWatcher.Tests/
│   └── ConnectionWatcher.UiSmoke/
├── docs/
├── learning/
├── scripts/
│   └── build-release.ps1
├── packaging/
└── Final-Share/
    ├── TCP-Connection-Watcher-Setup-win-x64.exe
    ├── SHA256SUMS.txt
    └── Docs/
```

- `ConnectionWatcher.sln`：整個專案的方案檔。
- `src/ConnectionWatcher.Core`：設定、規則、Windows TCP連線讀取、以時間為基礎的連線追蹤、處理程序背景資料，以及向下相容CSV記錄等核心邏輯。
- `src/ConnectionWatcher.App`：支援七種語言的Windows介面，包含主視窗、規則編輯器、事件詳細資料、內建說明中心、更新檢查、系統匣提示與警報視窗。
- `tests`：20項功能與相容性測試，以及多語言介面與DPI縮放測試。
- `docs`：七種語言的專案說明與使用說明。
- `learning`：開發者教學與架構學習資料。
- `scripts/build-release.ps1`：執行驗證，並依序自動產生`artifacts`、`dist`和`Final-Share`。
- `packaging`：安裝程式定義與可攜版說明。
- `Final-Share`：本機且不納入Git的最終分享資料夾，包含一個多語言安裝程式、七種語言的文件、發行說明和SHA-256校驗值。

## 建置與驗證

在Windows上建置原始碼需要.NET 8 SDK。

```powershell
dotnet build ConnectionWatcher.sln --configuration Release
dotnet run --project tests\ConnectionWatcher.Tests\ConnectionWatcher.Tests.csproj --configuration Release
```

發行套件包含`SHA256SUMS.txt`，接收者可使用PowerShell的`Get-FileHash`驗證。

維護者可以執行`scripts\build-release.ps1`，一次完成建置、測試、發佈、打包、複製最新文件與產生校驗值。
