## 專案背景與意義

Windows 資源監視器可以顯示目前的網路活動，但使用者必須一直開啟並觀察它。短暫連線可能在被注意之前就消失，也不方便長期保存指定目標的記錄。

SocketSight 讓使用者用規則指定要關注的遠端 IP、遠端連接埠或本機連接埠。程式只處理符合規則的 TCP 連線，並記錄出現時間、狀態、已觀察時長、Windows 回報的程序，以及能取得的應用程式背景資訊。

它不是資源監視器或防毒軟體的替代品，而是讓指定連線更容易持續觀察和事後查看，方便使用者或資安人員進一步調查。

## 專案概述

SocketSight 是一款在 Windows 本機執行、以規則為基礎的 TCP 連線觀察工具。開始監控後，程式會依照設定的間隔讀取 Windows TCP 連線表，並處理符合已啟用規則的連線。

預設檢查間隔為 1 秒。使用者可以用 0.5 秒為步進，在 0.5–10 秒之間調整。間隔越短越容易發現短暫連線，但檢查次數較多；間隔越長則較省資源，但可能錯過短暫連線。

程式只會處理規則指定的連線，不會把其他網路活動自動判斷為可疑。本版本專注於 TCP；UDP 需要不同的底層追蹤方式和更複雜的應用程式歸屬判斷，因此暫不包含在本版本中。

## 核心設計

- **規則優先**：只有符合已啟用規則的連線才會被處理。
- **每條連線只觀察一次**：持續存在的連線不會每秒重複寫入。
- **依真實時間判斷結束**：連線從清單消失滿 2 秒後才結束；期間重新出現仍是同一筆觀察記錄。
- **應用程式資訊是線索**：程序、PID、檔案、父程序和 Windows 服務資訊可以協助調查，但不能證明最終原因。
- **畫面與資料分開**：「清空顯示」只隱藏舊事件，不刪除 CSV 記錄。
- **預設在本機運作**：程式不讀取封包內容，也不會上傳規則和記錄。只有使用者手動檢查更新或開啟回饋頁面時才會連線 GitHub。

## 專案結構

```text
connection-watcher/
├── ConnectionWatcher.sln
├── RELEASE_NOTES.md
├── src/
│   ├── ConnectionWatcher.Core/       # 規則、監控、狀態、記錄和設定
│   └── ConnectionWatcher.App/        # WinForms 介面、語言、系統匣和啟動流程
├── tests/
│   ├── ConnectionWatcher.Tests/      # 核心功能與相容性測試
│   └── ConnectionWatcher.UiSmoke/    # 語言、DPI 和版面測試
├── docs/                             # 各語言專案說明與使用說明
├── learning/                         # 開發者教程與學習資料
├── scripts/build-release.ps1         # 建置、測試、封裝和發佈準備
├── packaging/                        # Inno Setup 安裝程式定義
└── Final-Share/                      # 給使用者的最終分享檔案
```

- `ConnectionWatcher.Core` 負責規則判斷、讀取 Windows TCP 表、追蹤連線、收集程序背景、CSV 記錄和設定。
- `ConnectionWatcher.App` 負責介面、規則編輯、事件詳細資料、說明中心、系統匣提示、警報、語言切換和啟動畫面。
- `tests` 保護核心行為，並檢查不同語言和顯示比例。
- `scripts` 會建置、測試、發佈自包含程式、建立安裝程式、複製最新文件並產生 SHA-256 校驗檔。
- `artifacts` 是原始發佈輸出，`dist` 是安裝程式輸出，`Final-Share` 是給使用者的最終分享內容；三者都可以重新產生。

使用者只需下載一個安裝程式：`SocketSight-Setup-win-x64.exe`。安裝後使用自包含的多檔案部署，不需要另外安裝 .NET 執行環境。

## 啟動、語言與說明中心

安裝程式支援七種語言。安裝時選擇的語言也會成為 SocketSight 的介面語言。升級安裝時重新選擇的語言會覆蓋原本的介面語言一次，但不會刪除規則、設定或記錄。

如果啟動時間超過約 0.5 秒，SocketSight 會顯示簡短的本機啟動畫面。輪換文字只是狀態提示，不代表程式正在連線網路或執行額外掃描；主視窗準備好後畫面會自動關閉。

設定中的說明中心會依目前介面語言顯示專案說明和使用說明。更新檢查必須由使用者手動執行，程式不會自動下載、安裝或執行更新。

## 建置與驗證

在 Windows 上建置需要 .NET 8 SDK 和 Inno Setup。

```powershell
dotnet build ConnectionWatcher.sln --configuration Release
dotnet run --project tests\ConnectionWatcher.Tests\ConnectionWatcher.Tests.csproj --configuration Release
```

維護者可以執行：

```powershell
scripts\build-release.ps1
```

此腳本會依序完成建置、測試、發佈、建立安裝程式、整理最新文件和產生 SHA-256 校驗檔。接收者可以用 PowerShell 的 `Get-FileHash` 檢查安裝程式。
