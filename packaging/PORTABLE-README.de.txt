TCP-Verbindungsmonitor 1.3.0

Verwendung
----------
1. Entpacken Sie die gesamte ZIP-Datei in einen Ordner.
2. Doppelklicken Sie auf ConnectionWatcher.exe.
3. Wählen Sie die Sprache, erstellen und aktivieren Sie eine Regel und klicken
   Sie anschließend auf Überwachung starten.

Die portable Version benötigt weder eine Installation noch Administratorrechte.
Einstellungen und Protokolle werden dennoch hier gespeichert:
%LOCALAPPDATA%\ConnectionWatcher

Wichtig
-------
Dieses Tool meldet nur Verbindungen, die benutzerdefinierten Regeln entsprechen.
Ein Treffer ist kein Beweis für Schadsoftware. Version 1 überwacht nur TCP.
