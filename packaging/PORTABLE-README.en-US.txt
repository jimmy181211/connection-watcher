TCP Connection Watcher 1.2.0

How to use
----------
1. Extract the entire ZIP file to a folder.
2. Double-click ConnectionWatcher.exe.
3. Choose the interface language, create and enable a rule, and then select
   Start monitoring.

The portable edition does not require installation or administrator rights. It
still stores its settings and logs under:
%LOCALAPPDATA%\ConnectionWatcher

Important
---------
This tool reports only connections matching rules created by the user. A rule
match is not proof of malware. Version 1 monitors TCP only.
