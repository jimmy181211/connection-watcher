# SocketSight

SocketSight is a local Windows tool for monitoring TCP connections. It helps users inspect active connections and understand which applications and processes are related to them.

## Features

- Rule-based local TCP connection monitoring
- Configurable connection check intervals
- Application and process context for detected connections
- CSV event logging
- A clear event log with detailed connection information
- User-reviewed feedback through a pre-filled GitHub Issue
- Manual update checking without automatic installation

## Project Status

SocketSight is an ongoing personal project. The current release includes improvements to the interface, event logging, process information, and release workflow.

See the [latest release](https://github.com/jimmy181211/connection-watcher/releases/latest) for the current version.

## Privacy and Scope

SocketSight is designed for local use. It does not automatically upload logs or install updates. Process information is based on what Windows can report at the time of detection, so attribution may not always be complete.

## Technology

- C#
- Windows desktop development
- TCP connection monitoring
- CSV-based event logging
